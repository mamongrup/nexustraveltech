NEXUS TravelTech Laragon kurulumu

1. Bu klasoru C:\laragon\www\nexustraveltech olarak kopyalayin.
2. Laragon'u acin ve Start All deyin.
3. Tarayicida http://localhost/phpmyadmin adresini acin.
4. database/schema.sql dosyasindaki SQL'i calistirin.
5. Site: http://localhost/nexustraveltech/
6. Admin panel: http://localhost/nexustraveltech/admin/
